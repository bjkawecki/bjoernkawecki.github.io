Gute Dokumentation entsteht während der Entwicklung
Warum Dokumentation selten am fehlenden Willen scheitert
Documentation Engineering erklärt
Wann README-Dateien nicht mehr ausreichen

Dokumentation in Readme von Repo bezieht sich auf Code. Was fehlt ist Kontext: welches Produkt, welches System, welche Abläufe, welcher Kunde. Das kann in Teilen noch in eine Readme oder die Repo-Docs Für ein Repo ist das noch ok. was ist aber bei 5 oder mehreren?  Dann braucht es eine zentralisierte Zusammenführung des Wissens die über die bloße Code-Definition hinausgeht.
